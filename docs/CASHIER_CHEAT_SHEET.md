# Cashier Cheat Sheet — Customer-Aware Pricing

- Select Customer at start; header shows Type and Special Pricing status
- Chips:
  - “Special Price” when fixed price applied
  - “Customer Discount” when profile discount applied
  - “Stacked (n)” when multiple discounts applied
- Popover shows profile rules first; if none matched, it says “No special price matched; applied standard discounts”
- Per-bill Disable Discounts toggle is in Totals; by default, fixed prices remain (unless IT enabled setting)
- Receipts mark Special Price / Customer Discount tags per line and show discount total
